# 🚀 Website Analyzer Pro

**Website Analyzer Pro** is a high-performance, AI-powered web analysis platform built for developers, SEO specialists, and website owners. It provides deep insights into website architecture, SEO health, performance metrics, and link structures through advanced visualizations and real-time crawling.

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://website-analyzer-pro.vercel.app) 

---

## ✨ Key Features

### 🔍 Real-Time Website Crawling
- **Instant Site Mapping:** Discover every page, link, and asset on a domain.
- **Progress Tracking:** Watch the analysis happen in real-time with live progress bars and status updates.
- **Deep Discovery:** Identifies orphan pages, broken links (404s), and complex redirect chains.

### 📊 Comprehensive Dashboard
- **Overview:** High-level health scores and critical issue summaries.
- **Network Tab:** Dynamic, interactive 2D link graph using `Vis.js` to visualize how pages connect.
- **Statistics:** Performance distributions, content size breakdowns, and depth analysis using `Recharts`.
- **Audit:** Automated checklist of performance, accessibility, and security issues.
- **SEO Analysis:** Detailed meta-tag audits, heading structure checks, and technical SEO metrics.
- **Mind Map:** A hierarchical view of site structure to identify navigation bottlenecks.

### 🤖 AI Chat Assistant
- **Contextual Insights:** Ask questions about your analysis in plain English.
- **Actionable Advice:** Get AI-generated recommendations for fixing SEO and performance issues.

### 📱 Fully Responsive & Modern UI
- **Mobile-First Design:** Seamless experience across Mobile, Tablet, and Desktop.
- **Dark Mode Support:** Easy on the eyes for deep technical audits.
- **Fluid Animations:** Powered by `Framer Motion` for a premium, interactive feel.

## 🛠️ Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strictly Typed)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Visualizations:** [Vis-network (Vis.js)](https://visjs.org/), [Recharts](https://recharts.org/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **State Management:** [Zustand](https://zustand-demo.pmnd.rs/)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm / pnpm / yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/website-analyzer-pro.git
   cd website-analyzer-pro
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to see the app.
